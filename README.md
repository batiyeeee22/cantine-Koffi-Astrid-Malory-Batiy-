J'ai réalisé un petit programme en JavaScript qui calcule le montant d'une commande et affiche le récapitulatif directement dans le terminal.
Son fonctionnement est simple :
Il traite une commande à la fois, et une commande peut contenir plusieurs portions du même plat.
Pour le calcul, j'utilise une instruction "switch" qui détermine le prix en fonction du plat choisi.
Ensuite, j'utilise une boucle "for" pour afficher le résultat final : soit la monnaie à rendre au client s'il a donné plus, soit le montant qui manque s'il n'a pas donné assez.
